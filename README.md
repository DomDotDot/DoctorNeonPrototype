## 🚀 Как запустить проект (для разработки)

1. Установите **[Ren'Py SDK](https://www.renpy.org/latest/)** (версия 8.x+ рекомендуется).
2. Склонируйте этот репозиторий или скачайте ZIP.
3. Откройте Ren'Py Launcher.
4. Выберите **"Preferences" (Настройки)** -> **"Projects Directory" (Папка проектов)** и укажите путь, где лежит папка этого репозитория.
5. Нажмите **"Refresh"**. Проект появится в списке.
6. Нажмите **"Launch Project"**, чтобы запустить игру.

## 🛠 Процесс разработки (Git Flow)

Мы используем простую структуру веток для одиночной разработки:

*   🔴 **`main`** — Стабильная версия. Сюда попадает только проверенный код. Эта версия всегда должна запускаться без ошибок.
*   🟡 **`dev`** — Основная ветка разработки. Все новые идеи и текущая работа ведутся здесь.
*   🔵 **`feature/name`** — Временные ветки для создания крупных механик (например, `feature/inventory` или `feature/minigame`). После завершения они вливаются в `dev` и удаляются.
*   🔵 **`l10n_dev`** — Служебная ветка Crowdin (автоматические обновления переводов).

### Как внести изменения:
1. Переключитесь на ветку `dev`.
2. Внесите изменения в код/сценарий.
3. Проверьте работоспособность в Ren'Py.
4. Закоммитьте изменения (`git commit`).
5. Когда обновление готово к релизу — слейте `dev` в `main`.

## 🌍 Переводы и Локализация (Crowdin)

Мы используем **Crowdin** для управления переводами.
Игра использует формат **Gettext (.po/.pot)** для синхронизации.

[![Помочь с переводом](https://img.shields.io/badge/Translate_on-Crowdin-brightgreen?style=for-the-badge&logo=crowdin)](https://crowdin.com/project/thebrightestneon-sr)

### ✋ Для переводчиков (Translators)
> **Пожалуйста, не редактируйте файлы `.rpy` в папке `game/tl/` вручную!**
Ваши изменения будут перезаписаны при следующей синхронизации.

1.  Перейдите на страницу проекта в [Crowdin](https://crowdin.com/project/thebrightestneon-sr).
2.  Выберите язык.
3.  Переводите прямо в браузере. Ваши изменения автоматически попадут в игру.
4.  Если вы не знаете Русского (Source Language), вы можете использовать **English** перевод как опору внутри редактора Crowdin.

### 🛠 Для разработчиков (Как работает синхронизация)

Для синхронизации файлов `.rpy` (код Ren'Py) и `.po` (формат Crowdin) используем **[Ren'Py Translator ToolKit (renpy-ttk)](https://beuc.net/renpy-ttk/)**.

Система переводов работает через промежуточные файлы:
1.  `game/tl/pot/game.pot` — Шаблон (генерируется из Русского оригинала).
2.  `game/tl/english_us/game.po` — Файл переводов (синхронизируется с Crowdin).

### Установка инструмента
1.  Скачайте `renpy-ttk` (версия 1.10 или новее) с [официального сайта](https://beuc.net/renpy-ttk/).
2.  Распакуйте архив в вашу папку проектов Ren'Py (туда же, где лежит папка проекта).
3.  В Ren'Py Launcher появится проект **renpy-ttk**.

### Сценарий 1: Вы изменили русский текст (Оригинал)
Если вы отредактировали диалоги в `script.rpy`, нужно обновить шаблон для Crowdin:
1.  Запустите **renpy-ttk** через лаунчер.
2.  Выберите пункт **`tl2pot`** (Generate POT template).
3.  В списке проектов выберите папку проекта`.
4.  Это обновит файл `game/tl/pot/game.pot`.
5.  Закоммитьте и отправьте изменения (`git push`). Crowdin увидит новые строки.

### Сценарий 2: Вы хотите применить новые переводы
Crowdin (или ветка `l10n_dev`) обновил файл `.po`, но в игре текст старый? Нужно сделать Inject:
1.  Убедитесь, что у вас свежая версия файла `game/tl/english_us/game.po` (сделайте `git pull`).
2.  Запустите **renpy-ttk**.
3.  Выберите пункт **`mo2tl`** (Inject PO/MO into Ren'Py).
4.  Откроется проводник. Выберите папку языка (например, `tl/english_us`).
5.  Скрипт перезапишет файлы `.rpy` в папке перевода. Теперь игра отображает новый текст.

> **Важно:** Никогда не правьте текст перевода вручную в файлах `tl/english_us/*.rpy`. Ваши изменения будут затерты при следующей инъекции через `mo2tl`. Правьте либо в Crowdin, либо в файле `.po`.

### 🛠 Для программистов и моддеров

Если вы хотите добавить фичу или исправить баг:
*   Старайтесь не менять существующие файлы (`script.rpy`), если это не багфикс.
*   Лучше создайте новый файл (например, `game/scripts/my_feature.rpy`) — Ren'Py подхватит его автоматически. Это уменьшит конфликты при слиянии.
*   Используйте `init python` блоки или отдельные `labels`, чтобы ваша логика не ломала основной сюжет.
