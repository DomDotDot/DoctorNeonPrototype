# Руководство по созданию локализаций и переводов для Doctor Neon

Визуальная новелла **Doctor Neon** содержит более **125 000 слов** диалогов и сложный киберпанк-сюжет. Данное руководство поможет сообществу создавать качественные переводы интерфейса и текста новеллы на любые языки мира.

---

## 1. Структура мода-перевода

Перевод оформляется в виде стандартного пакета модификации в папке `mods/`:

```text
mods/
└── mod_spanish_translation/
    ├── mod.json                     <-- Манифест с секцией translation_data
    ├── icon.png                     <-- Квадратная 1:1 иконка перевода
    ├── flag.png                     <-- Иконка флага (64x64 или та же иконка)
    └── tl/
        └── spanish/                 <-- Папка с кодом языка Ren'Py
            ├── common.rpy           <-- Перевод системных строк и кнопок
            └── scripts/             <-- Перевод диалогов и глав
```

---

## 2. Манифест перевода (`mod.json`)

В манифесте обязательно указывается тип `"type": "translation"` и вложенный блок `"translation_data"`:

```json
{
  "id": "community_spanish_tl",
  "name": "Español (Comunidad)",
  "version": "1.0.0",
  "author": "Doctor Neon Spanish Team",
  "type": "translation",
  "description": "Полный перевод интерфейса и сюжета Doctor Neon на испанский язык.",
  "target_version": "0.8.x",
  "priority": 20,
  "icon": "icon.png",
  "translation_data": {
    "name": "Español 🇪🇸",
    "lang_code": "spanish",
    "font": "DejaVuSans.ttf",
    "flag": "mod_spanish_translation/icon.png",
    "progress": 100
  }
}
```

### Поля `translation_data`:
- `name`: название языка с флагом/символом, отображаемое на экране выбора языка.
- `lang_code`: внутренний идентификатор языка Ren'Py (латиница в нижнем регистре, например `spanish`, `toki_pona`, `de`, `fr`, `zh_cn`).
- `font`: используемый шрифт для текста (по умолчанию `DejaVuSans.ttf`). Если язык требует специфических символов (CJK, арабская вязка и т.д.), шрифт можно положить в папку мода.
- `flag`: относительный путь к иконке флага (если не указан, берется превью-иконка `icon.png`).
- `progress`: число от 0 до 100 — процент готовности перевода, отображаемый на полоске прогресса.

---

## 3. Формат файлов перевода Ren'Py

### Перевод системных строк (`translate <lang> strings:`):
В файле `tl/<lang_code>/common.rpy`:
```renpy
translate spanish strings:
    old "Играть"
    new "Jugar"

    old "Настройки"
    new "Opciones"

    old "Выход"
    new "Salir"

    old "SELECT LANGUAGE / ВЫБЕРИТЕ ЯЗЫК"
    new "SELECCIONAR IDIOMA"
```

### Перевод диалогов новеллы:
Для перевода сюжетного текста создаются блоки с хэшами строк Ren'Py:
```renpy
translate spanish chapter1_scene_01_a1b2c3d4:
    # ru: "Добро пожаловать в город Неона."
    doctor "Bienvenido a la ciudad de Neón."
```

---

## 4. Проверка и тестирование в игре

1. Скопируйте папку с переводом в `mods/` (например, `mods/mod_spanish_translation`).
2. Запустите Doctor Neon.
3. Откройте **Настройки -> Коммьюнити Контент**.
4. Включите режим коммьюнити контента (подтвердив предупреждение).
5. Убедитесь, что ваш мод отображается в списке со своей 1:1 иконкой и статусом «АКТИВЕН».
6. Перейдите в **Настройки -> Язык** — ваш язык появится в сетке доступных языков с пометкой `[МОД]`.
7. Кликните по языку: весь переведенный интерфейс мгновенно применится!

---

## 5. Включение перевода в официальный релиз игры

Если ваш перевод качественный, завершен и протестирован сообществом, свяжитесь с разработчиками Doctor Neon (через GitHub Issues или официальное сообщество). Полные и вычитанные коммьюнити-переводы могут быть интегрированы в официальный билд игры с указанием авторов в титрах («Об игре»).
