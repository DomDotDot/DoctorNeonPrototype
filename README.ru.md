## О проекте

**Блестящий Неон - Полутонный Резонанс** — сюжетная кинетическая визуальная новелла в сеттинге футуристического нео-нуара. Игра сочетает атмосферное повествование, глубокую проработку персонажей, кастомные визуальные шейдерные эффекты GLSL, динамическое звуковое окружение и полноценную нативную поддержку модификаций.

## Как запустить проект (для разработки)

### Предварительные требования

1. **[Ren'Py SDK](https://www.renpy.org/latest/)**: Версия **8.2+** (рекомендуется 8.5.x).
2. **[Git](https://git-scm.com/)** и **[Git LFS](https://git-lfs.com/)**: Обязательны для выкачивания тяжелых исходных ассетов.
3. **[Python 3.10+](https://www.python.org/)**: Для запуска линтеров и утилит автоматизации.

### Инструкция по настройке

1. **Клонирование репозитория и загрузка LFS-файлов:**
   ```bash
   git clone https://github.com/DomDotDot/DoctorNeonPrototype.git
   cd DoctorNeonPrototype
   git lfs install
   git lfs pull
   ```
2. **Установка Git Pre-commit хука (крайне рекомендуется):**
   ```bash
   python tools/install_git_hook.py
   ```
   *Этот хук автоматически пересчитывает объем реплик, слов и обновляет таблицы статистики в `README.md` и `README.ru.md` при каждом вашем коммите.*
3. **Настройка Git Rebase (предотвращает захламление истории мерджами):**
   ```bash
   git config pull.rebase true
   git config rebase.autoStash true
   ```
4. **Запуск через Ren'Py:**
   * Откройте **Ren'Py Launcher**.
   * Перейдите в **«Настройки» (Preferences)** ➔ **«Папка проектов» (Projects Directory)** и выберите каталог с этим репозиторием.
   * Нажмите **«Обновить» (Refresh)**, выберите **Doctor Neon** и нажмите **«Запустить проект» (Launch Project)**.

## Нативная система моддинга и коммьюнити-контента

В игру встроен **полноценный нативный менеджер и загрузчик модификаций**. Вам **не нужно** декомпилировать проект, распаковывать `.rpa`-архивы или редактировать исходники игры, чтобы создавать или ставить моды.

### Для игроков: Установка и управление модами

1. В **Главном меню** или в **Настройках** откройте раздел **«Коммьюнити Контент и Моды»**.
2. Включите мастер-тумблер: **🟢 ВКЛЮЧЕНО** (приняв предупреждение о стороннем контенте).
3. Нажмите кнопку **«Открыть папку модов»** и поместите распакованную папку с модом в открывшуюся директорию `mods/`.
4. Прямо из интерфейса менеджера модов можно:
   * **Включать и отключать моды** без перезапуска игры.
   * **Регулировать приоритет загрузки** (если моды заменяют одинаковые ресурсы).
   * **Искать и фильтровать** моды по типам (*Переводы*, *Замена ассетов*, *Сценарии*, *Модульные*).
   * **Настраивать моды** через удобные встроенные переключатели, слайдеры и выпадающие списки.

---

### 💻 Для создателей модов: Разработка модификаций

Каждый мод представляет собой отдельную папку в каталоге `mods/`:
```text
mods/
└── my_cool_mod/
    ├── mod.json            # Обязательно: Манифест с метаданными мода
    ├── icon.png            # Опционально: Иконка превью 128x128
    ├── settings.json       # Опционально: Схема внутриигровых настроек
    └── my_script.rpy       # Код мода на Ren'Py / Python, экраны, хуки
```

#### 1. Манифест мода (`mod.json`)
Создайте файл `mod.json` в корне папки вашего мода:

```json
{
  "id": "my_cool_mod",
  "name": "My Neon Overhaul",
  "version": "1.0.0",
  "author": "ВашНикнейм",
  "type": "modular",
  "description": "Добавляет шейдерные эффекты, кастомные сцены диалогов и HUD-оверлей.",
  "target_version": "0.8.x",
  "priority": 10,
  "icon": "icon.png",
  "has_settings": true,
  "settings_file": "settings.json"
}
```

#### Поддерживаемые типы модов (`type`)
* **`modular`**: Полноценные программные моды (логика Python, кастомные экраны, шейдеры, аудиоэффекты).
* **`translation`**: Фанатские переводы. Автоматически монтируются в систему локализации Ren'Py.
* **`asset_replacement`**: Замена графики, спрайтов, фонов или саундтрека игры без изменения оригинальных файлов.
* **`script`**: Сюжетные модификации, новые ветки диалогов, сайд-квесты или дополнительные главы.

#### 2. Mod API: Хуки событий и наэкранные оверлеи
Движок предоставляет чистое API для интеграции без конфликтов:

```python
init python:
    # 1. Регистрация обработчика события (хука)
    def on_game_pulse(*args, **kwargs):
        print("Хук мода получил событие game_pulse!")
    register_mod_hook("game_pulse", on_game_pulse)

    # 2. Регистрация наэкранного оверлея (category: "main_menu", "ingame" или "all")
    register_mod_overlay("my_custom_hud_screen", mod_id="my_cool_mod", category="ingame", order=10)

    # 3. Чтение настроек, заданных игроком в меню мода
    custom_volume = get_mod_setting("my_cool_mod", "neon_intensity", default=100)
```

#### 3. Интерактивные настройки мода (`settings.json`)
Если указан флаг `"has_settings": true`, менеджер модов автоматически сгенерирует меню настроек прямо в игре:
```json
{
  "neon_intensity": {
    "type": "slider",
    "title": "Интенсивность неонового свечения",
    "default": 80,
    "min": 0,
    "max": 100,
    "step": 5
  },
  "enable_cyber_sfx": {
    "type": "toggle",
    "title": "Кибернетический аудиофильтр",
    "default": true
  }
}
```

> **Готовый пример:** Изучите папку [`mods/mod_example_cyberpunk/`](mods/mod_example_cyberpunk/) — это полностью рабочий эталонный модульный мод с кодом, оверлеем, хуком и интерактивными настройками.

## Сборка дистрибутивов (Build)

Для создания готовой сборки игры под Windows, Linux или macOS:
1. Откройте проект в **Ren'Py Launcher**.
2. Нажмите **«Построить дистрибутивы» (Build Distributions)**.
3. Выберите нужные платформы.
4. Правила сборки в `game/options.rpy` автоматически исключат исходники из `source_assets/`, служебные файлы Git и временные файлы разработки.
