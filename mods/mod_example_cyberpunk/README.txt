Doctor Neon - Example Cyberpunk Mod
====================================
Это пример мода на замену ассетов для игры Doctor Neon.

Структура:
- mod.json  : Манифест с метаданными мода (название, автор, версия, тип, иконка).
- icon.png  : Квадратная превью-иконка 1:1, отображаемая в менеджере модов.
- audio/    : Пример папки с ресурсами для оверрайда звуков или музыки.
